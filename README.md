# 📊 수강생 대시보드

React로 구현한 수강생 정보 관리 대시보드입니다.

## ✨ 주요 기능

- 📁 엑셀 파일 업로드 및 자동 파싱
- 📋 '사전 설문_수강생 공유' 시트 데이터 읽기
- 👥 왼쪽 사이드바에서 수강생 목록 확인
- 📝 수강생별 상세 정보 표시
- 🎨 모던하고 직관적인 UI/UX

## 🗂️ 데이터 구조

엑셀 파일의 다음 컬럼을 지원합니다:

- 성함
- 조 편성
- 담당 코치
- 해결과제
- 희망 솔루션
- 현재 방식
- 개선 시도
- 기대효과

## 🚀 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

### 빌드

```bash
npm run build
```

## 💡 사용 방법

1. 애플리케이션을 실행합니다
2. "엑셀 파일 선택" 버튼을 클릭하여 .xlsx 또는 .xls 파일을 업로드합니다
3. 파일이 로드되면 왼쪽에 수강생 목록이 표시됩니다
4. 목록에서 수강생을 선택하면 오른쪽에 상세 정보가 표시됩니다
5. "새 파일 업로드" 버튼으로 다른 파일을 불러올 수 있습니다

## 🛠️ 기술 스택

- React 18
- Vite
- XLSX (엑셀 파일 파싱)
- CSS3 (모던 스타일링)

## 📝 엑셀 파일 요구사항

- 파일 형식: .xlsx 또는 .xls
- 시트 이름: '사전 설문_수강생 공유' (정확히 일치해야 함)
- 첫 행에 컬럼 헤더가 있어야 합니다

## 🎨 UI 특징

- 그라데이션 헤더 디자인
- 호버 효과와 부드러운 애니메이션
- 반응형 레이아웃
- 직관적인 네비게이션
- 깔끔한 카드 기반 정보 표시
